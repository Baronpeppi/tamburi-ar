Tamburi AR v9.3
=================
Fix für leichtes Eigenbewegen des Kastens im Kameramodus.

Geändert:
- camera-controls im Vollbild-Kameramodell deaktiviert
- keine automatische model-viewer-Interaktion mehr
- Kamera-Interpolation deaktiviert
- nach jeder Benutzer-Schwenkbewegung wird die Kamera sofort exakt fixiert
- Kasten bewegt sich nur noch durch Benutzeraktionen
- 1024 x 768 Export bleibt unverändert

Für GitHub nur index.html ersetzen.

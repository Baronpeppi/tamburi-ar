Tamburi AR v9.2
- basiert auf der funktionierenden v9.1
- im Vollbild-Kameramodus gibt es jetzt zwei Touch-Modi:
  * Bewegen: 1 Finger verschiebt, 2 Finger skalieren

- Export bleibt 1024 x 768 Pixel

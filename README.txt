Tamburi AR – Kurzanleitung

1. Der Ordner muss über HTTPS gehostet werden, damit AR auf Android zuverlässig funktioniert.
2. Lade den gesamten Ordner unverändert auf einen Webserver / Hosting-Dienst.
3. Öffne danach die HTTPS-Adresse der index.html auf dem Samsung Galaxy S24 Ultra.
4. Wähle 1, 2 oder 3 Kästen.
5. Tippe auf „In Umgebung anzeigen“.
6. Die Kamera öffnet sich über Android AR / Scene Viewer.
7. Bewege das Handy langsam, bis eine Fläche erkannt wird, und platziere den Kasten.

Dateien:
- index.html
- tamburi_1_kasten.glb
- tamburi_2_kaesten.glb
- tamburi_3_kaesten.glb

Hinweis:
Die Modelle sind maßstäblich angelegt. AR-Skalierung ist auf "fixed" gesetzt, damit der Nutzer
den Kasten nicht versehentlich frei skaliert.
